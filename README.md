# Omarchy Telegram Theme

![Omarchy Telegram Theme — три палитры оформления Telegram](assets/github-preview.png)

Автоматически переносит палитру Omarchy в **Telegram Desktop для Linux**: список чатов, сообщения, кнопки, папки и счётчики. Смена темы применяется к работающему Telegram без перезапуска. Подписи и кнопки полноэкранного просмотра фото/видео сохраняют светлый цвет на тёмной подложке.

**Первый импорт файла в Telegram выполняется вручную один раз.** После этого Telegram отслеживает изменения файла. Скрипт не входит в аккаунт, не отправляет сообщения и не редактирует `tdata`.

## Требования

- Linux, **Python 3.11+** (только стандартная библиотека), `curl` для быстрой установки либо `git` для клонирования.
- Omarchy с текущей палитрой `colors.toml` и хуками `~/.config/omarchy/hooks/theme-set.d/`.
- Telegram Desktop. Основная проверка проводилась с официальной Linux-версией; Telegram Web, мобильные приложения и нативный клиент macOS не поддерживаются. Flatpak/Snap отдельно не проверялись — песочнице может потребоваться доступ к файлу темы.
- Запускать от своего пользователя, **без sudo**. Никакие системные пакеты установщик не устанавливает.

## Установка одним скриптом

Скачать и запустить установщик релиза:

```bash
curl -fsSL https://raw.githubusercontent.com/vornashev/omarchy-telegram-theme/v1.0.0/setup.py -o /tmp/omarchy-telegram-setup.py
python3 /tmp/omarchy-telegram-setup.py install
```

Установщик скачает генератор и базовую палитру из того же релиза, проверит их SHA-256, установит хук и создаст файл темы. Исходный `setup.py` можно просмотреть перед запуском. Git и pip для этого способа не нужны.

Альтернатива: установка из клона, в том числе без сети после клонирования:

```bash
git clone https://github.com/vornashev/omarchy-telegram-theme.git
cd omarchy-telegram-theme
python3 setup.py install
```

### Однократное подключение в Telegram

1. Откройте **Настройки → Настройки чатов → ⋮ → Создать тему → Импортировать существующую тему**.
2. Выберите файл, путь к которому вывел установщик. Обычно это:
   `~/.local/share/omarchy-telegram/Omarchy.tdesktop-theme`.
3. Нажмите **Сохранить изменения / Keep changes**.
4. Убедитесь, что **Автоматический ночной режим / Auto-night mode** выключен, чтобы Telegram не заменял выбранную тему.

Не копируйте тему в другое место перед импортом: Telegram должен отслеживать именно генерируемый файл. Не публикуйте её как облачную тему для подключения автоматизации.

Теперь меняйте тему Omarchy привычным способом, например:

```bash
omarchy theme set nord
```

Telegram обновится автоматически. Если он закрыт, прочитает актуальный файл при следующем запуске. Если выбрать другую тему внутри Telegram, для возврата синхронизации нужно повторно импортировать файл.

## Настройка и управление

Команда устанавливается в `~/.local/bin/omarchy-telegram`. Если каталог отсутствует в `PATH`, используйте этот полный путь.

```bash
omarchy-telegram status                       # состояние установки и конфигурация
omarchy-telegram refresh                      # обновить тему сейчас
omarchy-telegram configure --accent '#88c0d0'  # свой акцент поверх палитры Omarchy
omarchy-telegram configure --background '#101315' --foreground '#cacccc'
omarchy-telegram configure --reset            # убрать все переопределения; следовать Omarchy
```

Зафиксировать источник цветов, независимо от текущей темы рабочего стола:

```bash
omarchy-telegram configure --palette ~/my-theme/colors.toml
omarchy-telegram configure --palette auto      # снова использовать текущую тему Omarchy
```

`--palette auto` меняет только источник; ранее заданные цвета сохраняются. Для полного возврата к значениям Omarchy используйте `--reset`.

Настройки хранятся в `~/.config/omarchy-telegram/config.json`:

```json
{
  "palette": "auto",
  "colors": {
    "accent": "#88c0d0"
  }
}
```

Поддерживаются `accent`, `background`, `foreground` в формате `#RRGGBB`. После ручного редактирования выполните `omarchy-telegram refresh`. Основные цвета исходного TOML: `background`, `foreground`, необязательный `accent` (запасной вариант — `color4`). Генератор корректирует некоторые цвета ради читаемости; это адаптация палитры, а не точная копия интерфейса Omarchy. Фон чата однотонный, без обоев рабочего стола.

## Обновление

Скачайте `setup.py` нового релиза и повторите `install`. Для клона:

```bash
git pull --ff-only
python3 setup.py install
```

Настройки и путь файла темы сохраняются, повторный импорт обычно не нужен. Установщик не перезаписывает изменённые вручную управляемые файлы: сначала сохраните свои правки и восстановите установленную версию. Фоновое скачивание обновлений отсутствует.

## Удаление

Сначала выберите другую тему в Telegram, затем:

```bash
omarchy-telegram uninstall
```

Удаляет установленную автоматизацию и восстанавливает файлы, которые существовали до установки. Готовая тема и конфигурация остаются на диске. Чтобы удалить и их, **сразу** используйте:

```bash
omarchy-telegram uninstall --purge
```

Если автоматизация уже удалена, оставшиеся файлы можно убрать вручную:

```bash
rm -f ~/.local/share/omarchy-telegram/Omarchy.tdesktop-theme
rm -f ~/.local/share/omarchy-telegram/.lock
rm -f ~/.config/omarchy-telegram/config.json
```

При миграции с прежней ручной установки установщик сохраняет заменяемые файлы в резервную копию. Удаление восстановит и старый хук, если он был: для полного отказа от прежней автоматизации уберите восстановленный хук отдельно. Команда сообщает, какие файлы восстановлены. Локальные правки защищены: удаление остановится, если управляемый файл изменился после установки.

## Какие файлы устанавливаются

| Путь по умолчанию | Назначение |
| --- | --- |
| `~/.local/bin/omarchy-telegram` | Команды управления |
| `~/.local/bin/omarchy-telegram-theme` | Генератор темы |
| `~/.config/omarchy/hooks/theme-set.d/telegram-theme` | Хук смены темы Omarchy |
| `~/.config/omarchy-telegram/config.json` | Настройки пользователя |
| `~/.local/share/omarchy-telegram/manage.py` | Установщик и управление |
| `~/.local/share/omarchy-telegram/base-night.tdesktop-palette` | Базовая палитра Telegram |
| `~/.local/share/omarchy-telegram/Omarchy.tdesktop-theme` | Файл, отслеживаемый Telegram |
| `~/.local/share/omarchy-telegram/installation.json` | Учёт установленных файлов |
| `~/.local/share/omarchy-telegram/backups/` | Заменённые при установке файлы, если были |
| `~/.local/share/omarchy-telegram/.lock` | Блокировка параллельной генерации |

Учитываются `XDG_CONFIG_HOME`, `XDG_DATA_HOME` и `XDG_STATE_HOME`; пользовательские команды всегда находятся в `~/.local/bin`. Для Omarchy с нестандартным XDG-путём проверьте, что он вызывает хук из того же каталога конфигурации.

## Если цвета не меняются

1. Выполните `omarchy-telegram status`, затем `omarchy-telegram refresh`.
2. Проверьте первый импорт файла и режим Auto-night mode в Telegram.
3. Если ручное обновление работает, а смена темы Omarchy нет, проверьте хук:
   `~/.config/omarchy/hooks/theme-set.d/telegram-theme`.
4. Поддерживаются текущий путь палитры `$XDG_STATE_HOME/omarchy/current/theme/colors.toml` (обычно `~/.local/state/...`) и прежний `~/.config/omarchy/current/theme/colors.toml`. Если ни одного нет, задайте путь через `configure --palette`.
5. Telegram может потребовать закрыть и снова открыть окно просмотра медиа, чтобы перерисовать уже открытый экран.

`status` проверяет файлы и настройки интеграции; он не проверяет, какая тема выбрана внутри Telegram. Самостоятельно изменять сгенерированный `.tdesktop-theme` бессмысленно: следующая генерация заменит правки.

## Разработка и проверки

```bash
python3 -m unittest discover -s tests -v
```

Тесты используют временный HOME: установка, повторная установка, настройка, хук, сохранение inode файла для Qt watcher, резервное копирование, удаление и защита локальных правок. Отдельно проверяется контраст счётчиков и медиа-подписей на светлой и тёмной палитрах. GitHub Actions запускает проверки на Python 3.11 и 3.14.

Сама смена темы не требует сети: генерация локальная. Установщик обращается только к GitHub для получения файлов, если запущен вне клона.

## Возможные улучшения

- Скриншоты нескольких тем на демонстрационных чатах без личных данных.
- Проверка и инструкция для Flatpak/Snap.
- Настройка собственного фона чата и более подробных цветовых переопределений.

Эти возможности пока не реализованы. Автоматический первый импорт через управление мышью не используется: он зависит от языка, расположения окон и версии Telegram.
